# Changelog

All notable changes to `deep-ui-qa` are documented here.

## [1.0.0] — 2026-11-04

Initial release.

- Nine-phase workflow: intake, recon, atlas, model, design, execute, second look, report, cleanup.
- Model-first black-box testing with perturbation experiments and cross-module relationship mapping.
- Layered test design catalog with per-control checklists and deep scenario lenses.
- Evidence discipline: oracle hierarchy, multi-surface verification, honest statuses, config ledger.
- Workspace initializer, validator and styled Excel report builder.
- Seven domain packs: SaaS, HR/payroll, finance, e-commerce, CRM, support, scheduling.
- Host compatibility guidance for Claude Code, OpenCode, Codex, Cursor, Windsurf, Gemini CLI and Copilot.
- Installers for bash and PowerShell, plus CI smoke tests.
